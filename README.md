<h1>🚀 Software Automation Tools</h1>

<p>
A web-based platform that integrates multiple automation tools into one system to simplify repetitive tasks
and improve productivity. The project automates data handling, email workflows, and media optimization
through a user-friendly interface.

<h2>🔧 Tools & Features</h2>

<!-- Import Data -->
<h3>📥 Import Data</h3>
<ul>
  <li>Uploads CSV files and imports data into selected database tables.</li>
  <li>Automatically maps fields and validates records.</li>
  <li>Stores clean and structured data for further automation.</li>
</ul>

<!-- Export Data -->
<h3>📤 Export Data</h3>
<ul>
  <li>Selects any database table to export records.</li>
  <li>Converts data into CSV format automatically.</li>
  <li>Sends the exported file to the user via email.</li>
</ul>

<!-- Bulk Emails -->
<h3>📧 Bulk Emails</h3>
<ul>
  <li>Sends mass emails to multiple users in one click.</li>
  <li>Supports rich text editor and file attachments.</li>
  <li>Uses background processing for fast delivery.</li>
</ul>

<!-- Email Tracking -->
<h3>📊 Email Tracking</h3>
<ul>
  <li>Tracks email open rates in real time.</li>
  <li>Monitors link click activity.</li>
  <li>Displays engagement statistics.</li>
</ul>

<!-- Image Compression -->
<h3>🖼️ Image Compression</h3>
<ul>
  <li>Reduces image size without losing quality.</li>
  <li>Allows users to select compression level.</li>
  <li>Optimizes images for faster loading.</li>
</ul>
